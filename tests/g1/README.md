# G1 comparator checks

Build with g++ -std=c++17 -O2 algorithms/makespan/list_insertion.cpp -o /tmp/list_insertion and run python3 tests/g1/verify.py /tmp/list_insertion. Explicit opt-in registry IDs are heft_insertion, peft_insertion and lookahead_insertion. Existing heft and peft are append-only.

HEFT follows Topcuoglu et al. (DOI 10.1109/71.993206). PEFT follows Arabnejad and Barbosa, Algorithm 1 (DOI 10.1109/TPDS.2013.57). Both use earliest adequate insertion gaps. The classic fixture is from manuscript commit b5f489d, reproducibility/examples/classic_topcuoglu.d3. HEFT and PEFT match the published classic example CPU lanes and endpoints (80 and 85) in Frontiers 10.3389/fenvs.2022.996483, Figure 3. The Lookahead value 76 on that input is an implementation regression value.

Lookahead follows Bittencourt et al., Algorithm 1 (DOI 10.1109/PDP.2010.56), unweighted maximum over all direct children. Within a trial, reserve children in HEFT priority order with insertion, accounting for committed parents and previously placed trial tasks. Ignore unscheduled external parents in the trial. Each candidate owns a full copy of placements and processor intervals. For all variants equal task priorities favor the lower ready task ID. Equal objective values favor smaller actual finish, then lower CPU ID. Exit tasks use EFT.

The independent schedule parser checks complete unique placement, order, durations, nonoverlap, precedence and transfers. Tests include a forced gap, a child-aware processor reversal, and 100 fixed-seed small graphs across all three methods. These fixtures are historical or diagnostic. No fresh cohort has been opened. On the PEFT Figure 1 reconstruction, Table 3 task order, CPUs and finish times match at all ten steps. A diagnostic build printing candidate.finish and score for each processor matched all 30 EFT and 30 optimistic EFT values. The corrected edge assignments were checked in part against Table 3, so this is a consistency replay. Figure 2 makespans also match for HEFT (133) and Lookahead (127). G1 passed on the declared integer D3 scheduling model. The nine-task fixture was transcribed directly from Figure 1, page 2 of the UNICAMP author PDF (SHA-256 1812411a99ed6e3c8b864defa0e8251c00989c74e671a09cad24375087f64a64). Both task orders and all nine processor/start/finish triples reproduce the depicted HEFT and Lookahead schedules, including task 7 finishing on R2 at 141 versus R1 at 143, and task 9 at 260 versus 184. A separate diagnostic build enumerating candidate CPUs in reverse with the same tie rule yielded byte-identical Lookahead output on all three reference graphs. The independent Python schedule checker also rejected all seven deliberately malformed schedules. No scheduler adjustment was required.
